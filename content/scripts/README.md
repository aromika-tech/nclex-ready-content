# Spoken scripts

One file per post that gets a voiced video: `post-NN.json`, with a `lines` list holding one `{"say": "..."}` per on-screen step of `design/build_video.py`. The steps are the title, the hook, the first three teaching points and the Australian practice note, so a script has six lines.

Write for the ear: short sentences, contractions, a question where a reader would pause, and acronyms spelt the way they are said (A, B, C). Each line must say the same thing as the card line it sits under. Nothing new, no extra claims, Australian English, no exclamation marks.

Scripts are written when the plan calls for that post's video, not all at once.
