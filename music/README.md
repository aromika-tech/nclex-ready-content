# Background music

Beds for Reels, Shorts and long-form videos. Every track is CC0 (public domain dedication) on OpenGameArt, checked on each track's own page on 23 October 2026. CC0 needs no credit line and allows commercial use, but the credit is kept in `licences.json` anyway.

`licences.json` records, for each file: title, mood, author, licence, source page, original file URL, a SHA-256 of the original download, the download date and the length. Keep it with the files. If YouTube or Meta ever raises a copyright claim on a video, the source page and checksum are the proof for the dispute.

`feel-good-island` is dual-licensed CC0 and OGA-BY 3.0. It is used under CC0.

Each bed is loudness-normalised to -20 LUFS so they all sit at the same level, and the video builder ducks them under the voiceover.

Content ID matches sound, not licences. A free track can still be claimed if someone else registered it. If a claim lands, dispute it with the record here, and drop that track from rotation.
